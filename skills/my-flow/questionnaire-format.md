# PM 問卷格式

叫 `to-questionnaire` 時照這份做，它的預設模板讓路。程式範本在同層 `questionnaire/template.py`（共用 CSS／JS 在 `questionnaire/base.css`、`base.js`）。

## 輸出

- 中文 HTML＋Markdown 各一份，檔名 `to-questionnaire-<slug>.html`／`.md`，存到交付資料夾（還沒建立就先建立，路徑見 conventions.md「交付資料夾」）；圖片另存一個資料夾，Markdown 用相對路徑引用。
- 做法：把 `template.py` 複製到 scratchpad，改「設定」區後執行。不要手寫 HTML。

## 版面

- 開頭：目的、From／To／回答的用途、背景（設計稿在哪、節點 ID）、作答方式、題目一覽。
- 上方固定列：作答進度、「複製回答」「下載回答（.md）」；填的內容存在瀏覽器裡。
- 依主題分 `##` 部分，最急的放最前面；最後一題「還有其他的嗎？」。
- 每題：
  - 標題一句話問一件事，右邊標追蹤清單題號（例 P65）。
  - 附設計稿或實機截圖，**紅框加編號**標出要看的地方；圖說寫畫面名稱與節點 ID。
  - 說明條列，用 ①②③ 對應紅框編號，講清楚為什麼要問（沒畫／前後不一致／跟之前的回覆衝突）。
  - 「App 目前做成」：暫定做法，讓 PM 同意時回「可以」就好。
  - 「想請 PM 確認」：要決定的事，給選項或例子。
- 用語白話，不放 code 名稱、色號以外的技術詞。

## 出完之後

- 用瀏覽器（127.0.0.1 起本機伺服器）逐張確認紅框框在對的位置。
- 追蹤清單（例：`待後端事項.md`）那幾題標「已出問卷」，附檔名與題號。
